# My Python Project

A sample Python project for demonstration purposes.

## Setup

```bash
# Create virtual environment
python -m venv venv

# Activate virtual environment
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

## Running Tests

```bash
pytest
```

## Project Structure

```
my-python-project/
├── src/              # Source code
├── tests/            # Test files
├── requirements.txt  # Project dependencies
└── README.md
```
